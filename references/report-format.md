# 组价成果输出格式（默认规范 v1，2026-01 确认版）

**本规范是本技能的默认输出格式。** 凡输出工程量清单组价、综合单价、招标控制价类成果，
一律按本格式出数（Excel 三表）；聊天内答复组价结果时按「呈现规范」同等展开。
格式源自两份确认范例的融合：《清单与定额格式参考》PDF（综合单价分析表列式）+ 组价表截图
（清单→定额→资源三级层次）。验证锚点：`清单示例_组价表.json` → 7 条清单、
分部分项合计 **39,968.75 元**（与范例逐数一致）。

## 一、三表结构（一个 xlsx，三张 sheet，顺序固定）

| 序 | Sheet 名 | 内容 | 对应范例 |
|---|---|---|---|
| 1 | 组价表 | 清单→定额→资源 三级层次明细 + 尾部合计 | 截图范例 |
| 2 | 综合单价分析表 | 清单/定额两级 × 人材机管利组成 | PDF 范例「表1-19」 |
| 3 | 编制说明与组价思路 | 依据、范围、计价思路、风险、价格取定 + 逐条计算链 | 两范例的说明栏 + 透明计算要求 |

## 二、表1「组价表」列定义（12 列，固定序）

| 列 | 字段 | 说明 |
|---|---|---|
| 1 | 序号 | 只在清单行填（1、2、3…） |
| 2 | 清单编号/定额编号 | 清单行填清单编码（如 01B001）；定额行填「册 编号」（如 修缮建筑 1-169）；资源行空 |
| 3 | 项目名称/子目名称/资源名称 | 定额行前缀「」；资源行前缀「√」 |
| 4 | 项目特征/工作内容/说明 | 清单行=项目特征；定额行=套用说明（换算、借套理由） |
| 5 | 单位 | 居中；m²/m³ 用上标，不用 m2/m3 |
| 6 | 定额消耗 | 资源行=单位消耗量（4 位小数） |
| 7 | 系数 | 人工系数/资源换算系数，1 不显示 |
| 8 | 定额工程量 | 定额行与资源行 = 清单量 × 含量（3 位小数） |
| 9 | 含量 | 定额行 = 1 清单单位所需定额单位数（4 位小数） |
| 10 | 单价(元) | 清单行=综合单价；定额行=定额单价（含系数）；资源行=资源有效单价 |
| 11 | 合价(元) | 2 位小数 |
| 12 | 出处/备注 | 见「四、出处标注」 |

### 行层次与分色（固定）

- **清单行**（淡蓝 #D9E1F2，加粗）：填列序号/编码/名称/特征/单位/工程量/综合单价/合价。
- **定额行**（淡绿 #E2EFDA）：「」+ 子目名，含量、定额工程量、定额单价、合价、出处。
- **资源行**（白底；未计价/暂估行用淡黄 #FFF2CC）：前缀「√」，人材机逐行列出。
- **分部标题行**（橙 #C55A11）：如「一、分部分项工程项目清单」。
- **合计行**（淡橙 #FCE4D6）：末行「分部分项 + 措施项目 合计」。
- 表头蓝底白字 #4472C4；表头上方 2–3 行小字注明清单/定额/价格依据与制表日期。

### 计数与闭合规则（出数必须遵守）

1. **含量** = 1 个清单单位所需定额单位数（含单位换算：清单 m / 定额 10m → 0.1）。
   定额工程量 = 清单工程量 × 含量。
2. **资源消耗量** = 单位消耗 × 换算系数（如保护性拆除人工 ×1.5）× 定额工程量。
3. **% 类资源行**（其他材料/其他机械 ×%）：资源行「单价」必须用 金额÷消耗量 反推
   有效单价——price 明细的"单价"列是计费基数，直接当单价乘会放大 100 倍（4143→41.43 的教训）。
4. **管理费/利润**以伪资源行「√管理费（(人工+机械)×费率%）」「√利润（…）」列出，
   单价列填元/定额单位值，合价 = ×定额工程量，使**资源行合计 = 定额行合价严格闭合**。
5. **三级对账**：资源行合价之和 = 定额行合价；定额行合价之和 = 清单行合价；
   清单综合单价 = Σ(定额单价 × 含量)，合价 = 综合单价 × 清单工程量。
6. **暂估/未计价主材**：无定额编号的行编码列填「（未计价主材/暂估）」，出处标
   「★暂估/未计价，结算按实调整」，单价待定的留空不编造。

## 三、表2「综合单价分析表」列定义（12 列，固定序）

序号 | 项目编码 | 项目名称 | 单位 | 数量 | 综合单价(元) | 人工费 | 材料费 | 机械费 | 管理费 | 利润 | 合价(元)

- 两级层次：清单行（i）+ 定额行（i.j）；组成五列均为**定额单位口径**（清单行按综合单价拆分）。
- 管理费、利润基数 = **人工费 + 机械费**（不是人材机）；综合单价 **不含增值税**。
- 数字格式：数量 3 位小数，金额 2 位小数。
- 表标题固定「表1-19 分部分项工程量清单综合单价分析表」（PDF 范例编号）。

## 四、出处标注（每个定额行必填，不得省略）

| 对象 | 出处格式 |
|---|---|
| 定额子目 | `{册}册 {编号}｜{标准号}｜原书P{页码}`（如：修缮建筑册 1-169｜DB13(J)/T 8557-2022｜原书P12） |
| 资源价格 | 信息价出处（《河北建设工程造价信息》期次+地区）或「2023 基期价」；缺价标「未计价」 |
| 清单编码 | 国标号（GB/T 50854-2024 等）或河北补充编码规则（01B001｜冀建建市函〔2025〕154号） |
| 换算/借套 | 写进定额行「说明」列（如：换碳化木扶手、借套靠墙扶手拆除、人工×1.5 依据条款） |

## 五、表3「编制说明与组价思路」固定七节 + 计算链

一、依据清单（GB/T 50500-2024、GB/T 50854-2024、河北 17 号指南）→ 二、依据定额
（DB13(J)/T 各册 + 勘误批次）→ 三、编制范围 → 四、组价思路（含量→定额工程量→
资源消耗→定额单价→综合单价 七步口径）→ 五、施工措施项目 → 六、风险提示
（禁写无限风险、清单缺陷四类、调差）→ 七、单价与价格取定（基期/信息价期次/暂估）。

其后附**逐条组价计算过程**，每条清单按固定句式展开（数字全部带出，禁止只写结果）：

```
「01B001 木构件拆除（原围挡栏杆及立柱）」清单工程量 55.8 m
· 子目 修缮建筑 1-169 …：含量 0.6452 → 定额工程量 = 55.8×0.6452 = 35.997（人工系数 1.5）
    资源消耗 = 单位消耗 × 1.5 × 35.997；定额单价 = 人工xx + 材料xx + 机械xx + 管理费xx + 利润xx = xx 元/m
    定额合价 = xx × 35.997 = xx 元
· 清单综合单价 = Σ(定额单价×含量) = xx 元/m；合价 = xx × 55.8 = xx 元
```

## 六、输入（组价任务 JSON）

结构见 `scripts/清单示例_组价表.json`。要点：
`工程{名称,专业,类别,税制,地区,期次}`、`编制信息{编制人,编制范围,…}`、
`清单[{编号,清单编码,名称,单位,工程量,特征,出处,子目[]}]`；
子目 = `{册,编号,含量,人工系数?,说明?}` 或未计价行 `{未计价主材,名称,单位,数量,单价?,说明}`。
编制人栏固定含「编制：（造价员）　审核：（一级注册造价工程师）」（GB/T 50500 第 1.0.4 条）。

## 八、聊天呈现规范（不出文件时同等适用）

答复组价/综合单价问题时，即使只出文字，也必须默认：
1. **三级层次**：清单行 → 「」定额行（册+编号+出处）→ √ 资源行（人材机管利）；
2. **计算链**：含量→定额工程量→资源消耗→定额单价→综合单价→合价 逐步带数；
3. **出处**：子目给册/编号/页码，价格给期次/地区，换算给依据条款；
4. **提示不省略**：缺价项、⚠废止子目、暂估/未计价项、条件措施未计取——必须显式转告；
5. 金额 2 位小数、消耗/含量 4 位小数、工程量 3 位小数；单位用 m²/m³ 上标。
